# Invoice Generation System - Client

A modern, highly responsive React application for managing and generating professional tax invoices. This frontend provides an elegant dark/light theme UI with a focus on seamless user experience, including mobile-responsive navigation and robust PDF generation.

## 🚀 Features
- **Modern Dashboard:** Overview of total revenue, active customers, and pending invoices.
- **Invoice Management:** Create, view, and bulk import invoices.
- **Premium Print Layout:** Carefully crafted A4 invoice layout adhering strictly to standard GST invoice formats.
- **PDF Generation & Printing:** One-click PDF download (via html2pdf.js) and direct browser printing (via react-to-print).
- **Responsive Design:** Mobile-first approach featuring bottom-tab navigation for smaller screens.
- **Excel Bulk Import:** Support for uploading multiple invoices via Excel format.

## 🛠️ Tech Stack
- **Framework:** React.js (via Vite)
- **Routing:** React Router v6
- **Styling:** Custom Vanilla CSS (Glassmorphism & CSS Variables for theming)
- **Icons:** Lucide React
- **PDF & Printing:** `react-to-print`, `html2pdf.js`
- **HTTP Client:** Axios
- **Excel Parsing:** `xlsx`

## 📦 Setup Instructions
1. Clone the repository
2. Run `npm install`
3. Start the development server using `npm run dev`
